# Doc Engine v2.7 (Splitter+) — Release Notes

**Fecha:** 2026-06-10
**Rama:** `feature/splitter-fiable-ux` (12 commits)

## 🎯 Lo más importante

### Splitter fiable
El troceado de PDFs masivos ya no depende solo de detectar la firma del
proveedor. Ahora el corte se decide por **proveedor + nº de albarán**:

- Dos albaranes seguidos del mismo proveedor → **se separan** (antes podían
  acabar juntos en un archivo).
- Un albarán de 2 páginas con cabecera repetida → **se mantiene entero**
  (antes podía partirse en dos).
- Las páginas escaneadas con restos de texto digital ahora **sí pasan por
  OCR**: el umbral pasa de "página 100% vacía" a "menos de 50 caracteres".

### Hasta ~2x más rápido con OCR
Se eliminó el doble OCR: el texto que el splitter extrae para decidir los
cortes se reutiliza en la clasificación. Cada página se OCR-ea **una sola
vez**, con el mismo pre-procesado de imagen y la misma configuración de
Tesseract en todas las fases (antes splitter y clasificador usaban ajustes
distintos y "leían" textos diferentes).

### Corrección de pérdida de datos
Los fragmentos sin texto legible antes se quedaban en la carpeta temporal y
se **borraban** en la limpieza final. Ahora se mueven siempre a
`Revision_Manual`.

## ✨ Mejoras de interfaz

- **La app recuerda tu sesión**: última carpeta de origen y destino, estado
  del checkbox de OCR y tema claro/oscuro (guardado en `data/settings.json`).
- **Destino = origen automático**: al elegir carpeta de origen, el destino se
  sincroniza solo. Si eliges un destino a mano, se respeta el tuyo.
- **Barra de progreso** con contador `Procesando X/Y: archivo.pdf`.
- El contador final de `Docs | Errores` ya no cuenta dos veces los
  fragmentos ilegibles.

## 🐧 Compatibilidad con Linux

- Las rutas de Tesseract y Poppler ya no apuntan a `.exe`: en Windows se
  siguen usando los binarios portables de `bin/`, y en Linux se usan los del
  sistema (`sudo dnf install tesseract tesseract-langpack-spa poppler-utils`).

## 🔧 Interno

- Nuevo módulo `app/core/ocr_utils.py`: única fuente de verdad para extraer
  texto de una página (nativo + OCR, `--psm 6`, umbral binario 10).
- Nueva función pura `agrupar_paginas()` en `app/core/splitter.py` con la
  lógica de corte, cubierta por tests unitarios.
- `proveedores.json` se cachea en memoria (antes se releía del disco en cada
  página analizada).
- Suite de tests con pytest: **22 tests** (`pytest.ini` limita la colección a
  `tests/`; los scripts manuales de la raíz no se ven afectados).

## ⚠️ Notas y deuda conocida

- La regla "mismo proveedor sin nº de albarán legible → corte" es una
  decisión de diseño documentada en el spec; si en la práctica corta de más,
  se invierte en un solo punto (cubierto por tests).
- Las actualizaciones de UI desde el hilo de trabajo siguen sin pasar por
  `self.after()` (fuera de alcance de esta versión, planificado como mejora
  futura).
- El botón Salir no se deshabilita durante el procesamiento.
